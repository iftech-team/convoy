# План переписывания Linux-версии Convoy: Electron → GTK4 + VTE

Рабочий документ. Не для коммита, не для публикации — личные заметки по рефакторингу.

**Дата:** 24 сентября 2026
**Статус:** M0–M8 выполнены, но для Windows и Linux план развёрнут —
см. [13-design-pivot.md](13-design-pivot.md). GTK-клиент остаётся в
`apps/linux/` как рабочий, новый фронт — `apps/convoy/` на Tauri.
**Решение:** Linux-версия Convoy переписывается с Electron на Rust + GTK4 + libadwaita + VTE.
Windows остаётся на существующем Electron-превью (`apps/desktop`), он не трогается.

## Краткая суть

Electron-превью — 2698 строк, из них ~1100 строк логики (тонкие обёртки над `git`,
PTY и JSON-файлом) и ~700 строк UI на ванильном DOM. Логика портируется на Rust
почти механически. Вся реальная работа — в UI.

VTE снимает терминальную подсистему целиком: PTY, парсинг escape-последовательностей,
скроллбек, рендер. Ни `node-pty`, ни `xterm.js`, ни WebGL-костылей.

Замер запущенного Electron-билда (одно окно, одна сессия, 7 процессов): **≈745 МБ
суммарного RSS**. Цель после порта: **80–150 МБ, один процесс**.

Полный объём: **7–9 недель**. Но M1+M2 (≈2 недели) дают рабочее приложение,
которым уже можно пользоваться каждый день.
